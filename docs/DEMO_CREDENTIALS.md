## Creating the demo data
```bash
pnpm db:up
pnpm db:migrate
pnpm db:seed                                   # admin, 27 categories, 20 fictional brands
pnpm --filter @shopsphere/api demo:seed        # sellers, buyers, 39 products, 135 reviews, coupons
```
Both seeds are idempotent. Product images are illustrations generated by `pnpm --filter @shopsphere/api demo:images` and hosted on Cloudinary; their URLs are committed in `apps/api/src/database/demo-images.json` so a fresh machine does not need to regenerate them.

## Demo coupons
`WELCOME10` (10% off, up to ₹200, min ₹499) · `FLAT100` (₹100 off ≥ ₹999) · `FESTIVE15` (15% off, up to ₹500, min ₹1,999). They are listed on the home page; apply them at checkout (one use per buyer). Place an order as a demo buyer, then sign in as the matching seller to fulfil it.

For the public deployment, set a distinct `SEED_ADMIN_PASSWORD` in the Render environment and share it with the reviewer privately.
